# Your Live Story Builder

A single-page tool for Creative Owners Club members to turn their own experience into a 3 to 5 minute story for a TikTok Live.

- Static site: just `index.html`, with no backend and no build step.
- Answers are saved in the visitor's browser (localStorage). Nothing is sent to a server.
- The finished story can be copied to the clipboard.

## Deploy

`render.yaml` defines a free Render static site (`live-story-builder`) that publishes the repo root.
